مرحلهٔ اول: ساخت اسکلت آزمایشگاه

فعلاً این ساختار را می‌سازیم:

~/ilan-lab/
├── workspace/
│   └── sample-project/
├── logs/
├── traces/
├── configs/
└── runner/

در این مرحله:

  • هیچ اتصال API نداریم.
  • هیچ کلید یا اعتبار مالی در اختیار Runner نیست.
  • پروژهٔ سالون دست‌نخورده می‌ماند.
  • ابزارهای Runner را با تست‌های مستقل بررسی می‌کنیم.

اولین دستور را داخل Ubuntu اجرا کن:

mkdir -p ~/ilan-lab/{workspace/sample-project,logs,traces,configs,runner}

ls -R ~/ilan-lab

خروجی را بفرست تا مطمئن شویم اسکلت اولیه درست ساخته شده است.

مرحلهٔ دوم: ساخت پروژهٔ نمونه

داخل Ubuntu این دستور را اجرا کن:

cd ~/ilan-lab/workspace/sample-project

بعد فایل برنامه را بساز:

cat > app.py <<'EOF'
def greet(name):
    return f"Hello, {name}!"

if __name__ == "__main__":
    print(greet("Ilan"))
EOF

و یک تست ساده:

cat > test_app.py <<'EOF'
from app import greet

def test_greet:
    assert greet("Ilan") == "Hello, Ilan!"
EOF

در این مرحله فقط دو فایل آزمایشی داریم:

  • app.py برای برنامه
  • test_app.py برای تست

بعد از ساخت، خروجی این دستور را بفرست:

ls -l
