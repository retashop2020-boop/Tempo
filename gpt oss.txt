           ```python
           from collections import defaultdict, deque
           from typing import Dict, Iterable, List, Set, Any

           class TaskSchedulerError(RuntimeError):
               """Base exception for scheduler problems."""


           class MissingDependencyError(TaskSchedulerError):
               """Raised when a dependency is not present in the task graph."""


           class CycleError(TaskSchedulerError):
               """Raised when a cycle is detected in the dependency graph."""


           def run_tasks(tasks: Dict[Any, Iterable[Any]]) -> List[Any]:
               """
               Execute tasks in an order that respects the dependencies.

               Parameters
               ----------
               tasks : dict
                   Mapping from a task id to an iterable of its dependencies.
                   All dependencies must be keys of ``tasks`` – otherwise
                   :class:`MissingDependencyError` is raised.

               Returns
               -------
               List[Any]
                   The tasks in the order they were executed.

               Raises
               ------
               MissingDependencyError
                   If a task refers to a dependency that is not in ``tasks``.
               CycleError
                   If the dependency graph contains a cycle.
               """

               # ------------------------------------------------------------------
               # 1. Validate input & build graph
               # ------------------------------------------------------------------
               # Count of incoming edges for every node
               indegree: Dict[Any, int] = defaultdict(int)
               # For each node, list of nodes that depend on it
               graph: Dict[Any, Set[Any]] = defaultdict(set)

               # Ensure every key appears in indegree (even if zero)
               for task in tasks:
                   indegree[task] = 0

               for task, deps in tasks.items():
                   for dep in deps:
                       if dep not in tasks:
                           raise MissingDependencyError(
                               f"Task {task!r} depends on unknown task {dep!r}"
                           )
                       graph[dep].add(task)
                       indegree[task] += 1

               # ------------------------------------------------------------------
               # 2. Kahn's algorithm
               # ------------------------------------------------------------------
               # Queue of nodes with no incoming edges
               ready = deque([t for t, d in indegree.items() if d == 0])
               order: List[Any] = []

               while ready:
                   current = ready.popleft()
                   order.append(current)

                   # Simulate execution – in real code replace with actual logic
                   # e.g., execute(current)

                   for succ in graph[current]:
                       indegree[succ] -= 1
                       if indegree[succ] == 0:
                           ready.append(succ)

               # ------------------------------------------------------------------
               # 3. Detect cycle
               # ------------------------------------------------------------------
               if len(order) != len(tasks):
                   remaining = set(tasks) - set(order)
                   raise CycleError(f"Cycle detected involving tasks: {remaining}")

               return order
           ```

           ### Why this works

           * **Validation** – we walk all declared dependencies; any missing key triggers an exception before
           execution starts.
           * **Cycle detection** – if after Kahn’s algorithm the number of processed nodes is smaller than the total,
           at least one node is part of a cycle. We raise an informative error.
           * **No infinite loop** – the algorithm terminates because each node is processed at most once.
           * **Independent tasks** – nodes with no dependencies start in `ready` and are processed immediately.

           ## 2.  A robust implementation

           We’ll use **Kahn’s algorithm** (BFS‑style topological sort).
           * It builds a graph of “incoming edge count” (`in_degree`) for each node.
           * It starts with all nodes that have zero incoming edges (i.e. no dependencies).
           * Repeatedly removes a node, “executes” it, and decreases the in‑degree of its successors.
           * If at the end not all nodes were removed, a cycle exists (or a dependency is missing).

           Kahn’s algorithm gives us both *execution order* and *cycle detection* in one pass.

           ```python
           from collections import defaultdict, deque
           from typing import Dict, Iterable, Set, List

           def run_tasks(tasks: Dict[str, Iterable[str]]) -> List[str]:
               """
               Execute tasks in an order that satisfies all dependencies.

               Parameters
               ----------
               tasks : dict
                   Mapping from task name to an iterable of dependency names.

               Returns
               -------
               order : list
                   List of task names in the order they were executed.

               Raises
               ------
               ValueError
                   * If a task refers to a dependency that is not in `tasks`
                     (missing dependency).
                   * If a cycle is detected.
               """
               # ------------------------------------------------------------------
               # 1.  Build graph data structures
               # ------------------------------------------------------------------
               # 1a.  adjacency list – successors for each node
               succ: Dict[str, Set[str]] = defaultdict(set)
               # 1b.  incoming edge count
               in_degree: Dict[str, int] = {task: 0 for task in tasks}

               for task, deps in tasks.items():
                   for dep in deps:
                       if dep not in tasks:
                           raise ValueError(f"Task '{task}' depends on unknown task '{dep}'.")
                       succ[dep].add(task)
                       in_degree[task] += 1

               # ------------------------------------------------------------------
               # 2.  Initialise queue with nodes that have no incoming edges
               # ------------------------------------------------------------------
               queue = deque([t for t, d in in_degree.items() if d == 0])
               if not queue and tasks:
                   # All nodes have an incoming edge → cycle (or missing dependency)
                   raise ValueError("No starting point – the graph contains a cycle or missing dependency.")

               # ------------------------------------------------------------------
               # 3.  Process nodes
               # ------------------------------------------------------------------

                       if in_degree[nxt] == 0:

               # ------------------------------------------------------------------

                   # Find which nodes were not visited
                   missing = set(tasks) - set(order)
                   raise ValueError(f"Cycle detected (or missing dependencies) involving: {',
           '.join(sorted(missing))}")

               return order
           ```

           ## 2.  Robust implementation

           Below is a self‑contained module that meets the above requirements.
           It uses **Kahn’s algorithm** (BFS topological sort) because it gives us a
           natural way to detect cycles: if after the algorithm the number of processed
           tasks is less than the total number of tasks, a cycle exists.

           ```python
           #!/usr/bin/env python3
           """
           task_scheduler.py
           ~~~~~~~~~~~~~~~~~
           A tiny, dependency‑aware task runner that detects cycles and missing
           dependencies before executing anything.
           """

           from collections import deque
           from typing import Callable, Dict, Iterable, List, Set

           # ---------------------------------------------------------------------------

           def run_tasks(
               tasks: Dict[str, Iterable[str]],
               executor: Callable[[str], None] = None,
           ) -> List[str]:
               """
               Execute all tasks in a dependency‑safe order.

               Parameters
               ----------
               tasks:
                   Mapping of task name → iterable of dependency names.
               executor:
                   Callable that receives a task name and performs the work.
                   If omitted, ``print`` is used (so the function is still usable
                   as a demonstration).

               Returns
               -------
               order:
                   List of task names in the order they were executed.

               Raises
               ------
               ValueError:
                   * If a task depends on a name that does not exist in ``tasks``.
                   * If the dependency graph contains a cycle.
               """
               if executor is None:
                   executor = print  # default simple executor

               # -----------------------------------------------------------------------
               # 1. Build graph and indegree table
               # -----------------------------------------------------------------------
               indegree: Dict[str, int] = {task: 0 for task in tasks}
               graph: Dict[str, List[str]] = {task: [] for task in tasks}

               for task, deps in tasks.items():
                   for dep in deps:
                       if dep not in tasks:
                           raise ValueError(
                               f"Task '{task}' depends on missing task '{dep}'."
                           )
                       graph[dep].append(task)      # dep → task
                       indegree[task] += 1

               # -----------------------------------------------------------------------
               # 2. Initialize queue with zero‑indegree nodes (tasks with no deps)
               # -----------------------------------------------------------------------
               queue: deque[str] = deque([t for t, d in indegree.items() if d == 0])
               order: List[str] = []

               # -----------------------------------------------------------------------
               # 3. Kahn's algorithm
               # -----------------------------------------------------------------------
               while queue:
                   current = queue.popleft()
                   executor(current)
                   order.append(current)

                   for neighbour in graph[current]:
                       indegree[neighbour] -= 1
                       if indegree[neighbour] == 0:
                           queue.append(neighbour)

               # -----------------------------------------------------------------------
               # 4. Cycle detection
               # -----------------------------------------------------------------------
               if len(order) != len(tasks):
                   # Determine which nodes are part of the cycle(s) for a better error
                   remaining = set(tasks) - set(order)
                   raise ValueError(
                       f"Cycle detected involving tasks: {', '.join(sorted(remaining))}"
                   )

               return order

           # ---------------------------------------------------------------------------

           # For quick manual testing (if this file is run directly)
           if __name__ == "__main__":
               sample = {
                   "A": [],
                   "B": ["A"],
                   "C": ["A"],
                   "D": ["B", "C"],
               }
               run_tasks(sample, executor=lambda t: print(f"Running {t}"))
           ```

           ## 2. A robust, cycle‑detecting implementation

           We’ll use **Kahn’s algorithm** for topological sorting:

           1. Build a graph: adjacency list and indegree counts.
           2. Validate that every dependency is a defined task.
           3. Put every node with `indegree == 0` into a queue.
           4. Repeatedly pop a node, *execute* it, and decrement the indegree of its neighbours.
           5. If at the end not all nodes were processed → a cycle exists → raise an exception.

           This algorithm guarantees:

           * **No infinite loop** – the queue can only become empty if no progress is possible.
           * **Cycle detection** – the algorithm detects it *before* any task is executed.
           * **Missing‑dependency detection** – we fail fast when an undefined dependency is seen.

           ```python
           from collections import deque
           from typing import Dict, Iterable, List, Set, Callable

           def run_tasks(
               tasks: Dict[str, Iterable[str]],
               execute: Callable[[str], None] = None
           ) -> List[str]:
               """
               Execute tasks in a valid order respecting dependencies.

               Parameters
               ----------
               tasks : dict
                   Mapping from task name to an iterable of dependency names.
               execute : callable, optional
                   Function called as execute(task_name).  If None, no side‑effects occur.

               Returns
               -------
               order : list
                   The tasks in the order they were executed.

               Raises
               ------
               ValueError
                   If a task declares a dependency that is not a key in ``tasks``.
               RuntimeError
                   If a cycle exists in the dependency graph.
               """
               # 1. Normalise input and build adjacency list
               graph: Dict[str, Set[str]] = {t: set() for t in tasks}
               indegree: Dict[str, int] = {t: 0 for t in tasks}

               for t, deps in tasks.items():
                   for d in deps:
                       if d not in graph:
                           raise ValueError(f"Task '{t}' depends on unknown task '{d}'.")
                       # Avoid counting duplicate edges twice
                       if d not in graph[t]:
                           graph[t].add(d)
                           indegree[d] += 1

               # 2. Queue of tasks that can be executed immediately
               q = deque([t for t, deg in indegree.items() if deg == 0])
               order: List[str] = []

               while q:
                   t = q.popleft()
                   if execute:
                       execute(t)          # side‑effectful user code
                   order.append(t)

                   # Decrease indegree of all tasks that depend on *t*
                   for u in graph:
                       if t in graph[u]:
                           indegree[u] -= 1
                           graph[u].remove(t)    # optional, helps debugging
                           if indegree[u] == 0:
                               q.append(u)

               if len(order) != len(tasks):
                   # Find the remaining tasks that form a cycle
                   cycle_tasks = set(tasks) - set(order)
                   raise RuntimeError(f"Cycle detected involving tasks: {sorted(cycle_tasks)}")

               return order
           ```
